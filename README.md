# アメコミ図鑑

出版社 → コミック・アニメ・映画・ゲーム → シリーズ → 作品 → 表紙一覧／キャラクター一覧 → ヴァリアント画像、とたどれる自分だけのアメコミ図鑑です。

**アプリを開く：https://pitapaka37-prog.github.io/amecomi-zukan/**

## スマホでアプリにする
- iPhone：Safari で上の URL を開く → 共有ボタン → 「ホーム画面に追加」
- Android：Chrome で開く → 右上の「︙」→ 「アプリをインストール」または「ホーム画面に追加」

ホーム画面のアイコンから全画面で起動し、一度開けば電波がなくても使えます。

## データについて
図鑑の中身（出版社・作品・画像など）は、使う人のスマホやブラウザの中だけに保存され、どこにも送られません。
友達が開くと、友達専用の図鑑になります。ブラウザの「履歴とサイトデータを消去」をすると中身も消えます。

## 更新するとき
`index.html` を差し替えたら、`sw.js` の `VERSION`（例：`amecomi-v1` → `amecomi-v2`）も変えてください。スマホ側に新しい版が確実に届きます。
